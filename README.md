# UNINGRAT Digital Systems

Organization resmi **Universitas Doktor Husni Ingratubun (UNINGRAT) Papua** untuk pengelolaan source code dan dokumentasi sistem informasi kampus.

> ⚠️ Sebagian besar repository di organization ini bersifat **privat** karena berisi source code sistem produksi, konfigurasi server, dan data internal kampus. Akses diberikan secara terbatas kepada tim pengembang dan administrator sistem UNINGRAT.

## 🎯 Tujuan

- Menjadi pusat version control untuk seluruh sistem digital kampus
- Menjaga keamanan dan kerahasiaan source code sistem akademik & administrasi
- Mendukung kolaborasi tim internal (developer, admin sistem TI)
- Memudahkan maintenance dan transfer pengetahuan antar anggota tim/generasi developer
